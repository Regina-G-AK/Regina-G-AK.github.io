广告业务入门

Author: Regina Date: 四月 17, 2026  20:23:28 Category: 面试

1. 业务逻辑与生态层

  • 核心角色： 广告主（出钱的人）、媒体/平台（出流量的人）、用户（看广告的人）。

  • 商业模式： 比如搜索广告（意图导向）、社交/推荐广告（兴趣导向）。

  • 广告主 (Advertiser - 需求方)：

    • 诉求： 以最低的成本（CPA）获得最高的转化（ROI）。
    • 分类： 品牌广告主（要名声，如可口可乐）vs 效果广告主（要转化，如电商、游戏）。

  • 平台/媒体 (Publisher - 供给方)：

    • 诉求： 流量变现效率最大化（eCPM），同时保证不伤害用户留存。
    • 资源： 广告位（信息流、开屏、搜索位）。

  • 用户 (User - 流量来源)：

    • 诉求： 消费优质内容，不希望被无关、低质的广告打扰。

生态流转机制

  1. 流量生产： 用户刷新抖音（产生一次请求）。
  2. 画像匹配： 系统通过算法标签（年龄、地域、兴趣）识别该用户。
  3. 实时竞价 (RTB)： 成千上万的广告主在毫秒级时间内参与竞价。
  4. 广告分发： 综合 eCPM（出价×质量） 最高的广告胜出。
  5. 反馈回路： 用户点击或购买（数据返回系统），或用户举报（触发风控）。

A. 供需平衡分析 (Supply & Demand)

  • 分析点： 如果广告主变多了（需求旺盛），但用户流量没变（供给持平），会导致 CPM (流量价格) 飙升。
  • 商分动作： 评估是否需要提高 Ad Load (广告加载率) 来释放更多供给，还是引导广告主优化素材以提升转化。

B. 流量质量与分布

  • 分析点： 并不是所有流量都一样钱。搜索流量（主动意图）通常比信息流流量（被动推荐）转化率更高。
  • 商分动作： 拆解不同流量入口的 ARPU (每用户平均收益) 值，优化流量分配策略。

C. 损耗与摩擦 (Friction)

  • 分析点： 从广告主投钱到最终产生订单，中间有多少环节在“漏钱”？（如我们之前聊的技术加载问题、审核过慢问题）。
  • 商分动作： 识别并减少生态中的非效率环节。

生态逻辑总结： 平台通过免费内容吸引用户流量 $\rightarrow$ 流量被算法转化为高价值的“标签流量” $\rightarrow$ 广告主通过竞价购买匹配的标签 $\rightarrow$ 平台赚到钱后再投入内容生产，形成闭环。

2. 核心指标与量化层

营销漏斗：看-点-转化-留存

2.1 流量与感知层

  • 展现量 (Impression): 广告被加载出来的次数。
  • 触达人数 (Reach): 广告覆盖的去重用户数。
  • CPM (Cost Per Mille): 千次展现成本。在字节的竞价环境中，CPM 反映了该人群包的竞争激烈程度。
  • ePCM: 期望千次展示收益。
    $$ePCM=pCTR(\text{预估点击率})\times pCVR(\text{预估转化率})\times Bid(\text{出价})\times 1000$$

负向外部性：

  • 用户体验：负反馈率、短时间内的 App 卸载率
  • 内容生态：广告/内容比
  • 长期价值：用户生命周期价值

2.2 互动与兴趣层

  • CTR (Click-Through Rate): 点击率（点击/展现）。反映了素材标题或封面的吸引力。
  • 播放时长相关指标:
    • 2s/3s播放率: 反映“黄金开头”的抓人能力。
    • 完播率 (Full Video View Rate): 反映内容质量和受众精准度。
  • 互动率: 包括点赞、评论、分享、关注。这些行为在字节算法中往往具有很高的权重。

2.3 转化与行动层

  • CVR (Conversion Rate): 转化率（转化/点击）。反映落地页或购买流程的效率。
  • CPA (Cost Per Action): 激活/转化单价。这是优化师最盯着的指标。
  • ROI (Return on Investment): 投资回报率（销售额/广告支出）。在电商直播中，也常用 ROAS (Return on Ad Spend)。

2.4 长期价值与质量层

  • LTV (Lifetime Value): 用户生命周期价值。
  • 负反馈率: 如点击“不感兴趣”、举报。高负反馈率会触发风控，导致流量被限。

2.5 流量漏斗分析

  1. 点击-到达率
    • 定义： 落地页成功加载的人数 / 广告点击数。
    • 分析点： 如果这个比例低于 80%，通常意味着：
      • 技术故障： 链接失效（404）、服务器响应慢。
      • 环境问题： 页面包体太大，在弱网环境（3G/移动中）打不开。
      • 劫持问题： 流量在跳转过程中被恶意拦截或劫持。
  2. 二跳率 / 停留时长
    • 定义： 用户进入页面后是否有进一步操作，或待了多久。
    • 分析点： 如果到达率很高但停留极短，说明进店即走。这可能是货不对板或者页面 UI 设计极其反人类。
  3. 转化漏斗
    • 路径： 注册 -> 加入购物车 -> 付款成功。
    • 分析点： 每一个环节的转化率（Step CVR）。比如，如果注册环节流失重，可能是因为验证码发送太慢或强制要求实名认证。
模块 核心关注点 关键指标
1. 流量供给 (Supply) 平台有多少水（用户）？ DAU, 人均时长, Ad Load (加载率)
2. 拍卖竞价 (Auction) 谁能上场比赛？ eCPM, Bid, pCTR, pCVR
3. 投放效果 (Performance) 广告主赚到钱了吗？ ROI/ROAS, CPA, 回收周期
4. 用户路径 (Funnel) 流量在哪漏掉了？ 到达率, 转化率, 页面加载耗时
5. 生态健康 (Health) 平台环境坏了吗？ 负反馈率, 留存率影响, 作弊流量占比

3. 策略与算法分析层

3.1 竞价机制：解决“谁能赢”的问题

广告位是稀缺资源，必须通过拍卖（Auction）来决定归属。

  • GSP (广义第二价格) 竞价：
    • 规则： 赢家支付的是第二名（下一位）的出价 + 0.01元。
    • 目的： 鼓励广告主按真实心理价值出价，避免频繁调整价格的内耗。
  • VCG (Vickrey-Clarke-Groves) 机制：
    • 规则： 赢家支付其加入给其他竞争者带来的“效率损失”。
    • 应用： 逻辑更复杂，通常用于多广告位（如搜索结果页）的全局最优分配。

3.2 预估模型：解决“准不准”的问题

算法通过历史数据，实时预测一个广告被特定用户看到后的反应。

  • pCTR (Predict Click-Through Rate)： 预估点击率。判断用户是否会点开。
  • pCVR (Predict Conversion Rate)： 预估转化率。判断用户点开后是否会买。
  • 特征工程： 模型会考虑用户标签（性别、兴趣）、环境特征（时间、网络、机型）、广告素材特征（标题、行业）。
  • 商分视角： 如果模型预估不准（pCTR 偏离实际 CTR），会导致广告主成本暴涨或平台收入流失。

3.3 出价策略：解决“花多少”的问题

从传统的“手动出价”向“智能出价”演进是字节跳动等平台的关键。

  • CPC/CPM： 传统出价，由广告主控制风险。
  • oCPM / oCPX (Optimized CPM)： * 核心逻辑： 广告主设定转化目标出价（比如 50元买一个激活），系统根据 pCVR 自动折算成 CPM 进行竞价。
    • 两阶段投放： 第一阶段（积累期）通过高出价寻找转化人群；第二阶段（稳定期）模型成熟，出价趋于平稳。
  • 预算平滑 (Pacing)： 防止广告在早上 8 点就花光全天预算，系统会控制消耗节奏，确保全天均衡触达。

3.4 分发与重排策略：解决“排在哪”的问题

在最终展示前，系统还要进行最后一步的人为干预。

  • eCPM 排序： $$eCPM = Bid \times pCTR \times pCVR \times 1000$$这是最基础的排序逻辑。
  • 打分系数 (Boost/Weight)： 平台会给某些优质广告（高留存、低负反馈）加权，或给某些违规边缘广告降权。
  • 多样性限制： 避免同一个用户连续刷到三条游戏广告，算法会强制插入原生内容进行“去重”。
  • 冷启动策略： 对于新上线的广告，由于没有历史数据，系统会给予流量扶持，快速探测其质量。
分析场景 策略关注点 常用方法
收入波动分析 竞价环境是否发生剧变？ 观察 Win Rate (胜率) 和 Bid Landscape (出价分布)
广告主吐槽成本高 是否由于模型预估偏差？ 评估 pCTR vs. aCTR (预估与实际之比)
流量浪费严重 是否冷启动策略太激进？ 分析 废标率 或 低质流量占比

4. 风险、质量与反作弊层

4.1 业务合规与安全风险

  • 内容违规： 广告素材包含虚假宣传、欺诈、色情、暴力或政治敏感内容。
  • 行业准入： 某些行业（如医疗、金融、游戏）需要特定的资质。如果误放了无资质的广告，平台需承担连带责任。
  • 品牌安全（Brand Safety）： 确保广告不会出现在不适宜的内容旁边（例如，某航空公司的广告出现在空难新闻视频中），这会损害广告主的品牌形象。

4.2 流量与反作弊风险

  • 虚假流量（IVT）： 机器人模拟点击（Bot Click）、机刷量等。
  • 归因作弊： 恶意抢占归因（Attribution Scraping），导致广告主为原本就会产生的自然转化付费。

4.3 生态与用户体验风险

  • 用户负反馈： 广告频率过高（打扰用户）或相关性极差（用户不喜欢），导致用户流失、卸载 App。
  • 商业生态恶化： 劣质广告（Low-quality ads）驱逐优质广告，导致广告竞价环境混乱，长期看会降低平台的变现效率。
